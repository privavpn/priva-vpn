# Priva VPN

  A fast, private VPN client for Android — built on WireGuard®.

  ![Platform](https://img.shields.io/badge/platform-Android%208%2B-3ddc84)
  ![Protocol](https://img.shields.io/badge/protocol-WireGuard-88171a)
  ![Release](https://img.shields.io/github/v/release/privavpn/priva-vpn)

  Priva VPN is a clean, no-nonsense client focused on speed and privacy.
  No sign-up, no ads, no tracking — just import your subscription link and connect.

  ## Features

  - 🚀 **WireGuard-based** — fast, modern, and light on battery.
  - 🔒 **Private by design** — your keys are encrypted on your device and never leave it. No account, no personal data, no analytics.
  - ⚡ **One-tap connect.**
  - 📊 **Live status** — real-time download / upload speed and ping while connected.
  - 🟡 **Honest connection state** — a clear indicator when the link is up but weak, instead of spinning forever.
  - 🧩 **Split tunneling** — pick which apps use the VPN, or route by IP / domain; local network stays reachable.
  - 🗂 **Multiple subscriptions** in one app, with usage and expiry at a glance.
  - 🔑 **Easy import** — add a subscription via link or QR code.
  - 🔁 **In-app updates** — get new versions from inside the app.
  - 🛡 **Leak protection** — IPv6-leak handling, kill-switch, and always-on support.
  - 🌐 **English & Persian**, with light and dark themes.

  ## Requirements

  - Android 8.0 (API 26) or newer.

  ## Install

  1. Download the latest `priva-vpn-vX.Y.Z.apk` from the [Releases](../../releases) page.
  2. Open the file. If Android asks, allow installing from this source once.
  3. After the first install, the app keeps itself up to date — you'll be prompted in-app when a new version is available.

  ## Privacy & Security

  - Subscription tokens and WireGuard keys are stored encrypted via the Android Keystore.
  - Traffic to the service is authenticated and encrypted beyond TLS.
  - Minimal permissions, no ads, no third-party trackers.
